# 🤖 Migration Assistant Bot

A smart Telegram bot for immigration guidance — academic, work, and residency.

## ✨ Features
- AI-powered answers to immigration questions
- Guidance for academic and work immigration
- Persian language support

## 🚀 Usage
Just open Telegram and search for [@Lumininini](https://t.me/Lumininini) and start chatting!

## 🛠️ Self-Hosting

### Requirements
- Python 3.10+
- OpenRouter account
- Telegram bot token (from BotFather)

### Installation
```bash
pip install -r requirements.txt
```

### Environment Variables
Create a `.env` file:
```bash
TOKEN=your_telegram_token
OPENROUTER_API_KEY=your_openrouter_key
```

### Run
```bash
python bot.py
```

## 🚀 Deploy on Railway
1. Connect your repo to Railway
2. Add variables in Railway → Variables
3. Deploy!
